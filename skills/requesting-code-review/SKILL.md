# Requesting Code Review

Prepare a compact review package:
- spec/acceptance criteria;
- relevant decisions/rulings;
- diff range or changed files;
- verification evidence;
- known risks or intentional deviations.

Ask the reviewer to check correctness, spec compliance, architectural consistency, security, regressions,
maintainability, and tests. Treat findings by severity and evidence; fix load-bearing issues before completion.
