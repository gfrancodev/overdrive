# Cross-host run: 2.3.0-rc.1, 2026-10-18

Automated part of the [runbook](../CROSS_MACHINE_RUNBOOK.md), with `scripts/cross-host/run.sh`: three Debian 12
containers on one Docker network, each with its own address, linux/amd64, no Go or Rust. Each installed the
published `overdrive-linux-amd64.zip` (install: 3 seconds) and ran the Core as the tray starts it, on loopback.

| C, oldmac | Debian 12, linux/amd64 (container) | bundle v2.3.0-rc.1, no toolchain |
